Step 1 — PostgreSQL install karte hain (First Priority)
Is waqt sirf PostgreSQL install karein.
Main recommend karta hoon:
•	PostgreSQL 17 (latest stable)
•	pgAdmin 4 (saath hi install ho jayega)
•	Stack Builder ki zarurat nahi
•	Default port: 5432
Installation ke baad sirf ye yaad rakhein:
Host: localhost
Port: 5432
Database: postgres
Username: postgres
Password: (jo aap set karein)
Aur Windows Environment PATH mein psql add ho jaye to aur bhi achha.

Step 2 — Python packages
Agar Python installed hai to ye install karwa dein:
pip install psycopg2-binary
pip install sqlalchemy
pip install pandas
pip install openpyxl
Ye PostgreSQL se baat karne ke liye foundation hai.

Step 3 — dbt
Ab dbt bhi ready kar lete hain.
pip install dbt-core
pip install dbt-postgres
Baad mein verify:
dbt --version

Phir Codex ko pehla backend task
Usko seedha ye objective diya ja sakta hai:
Create the backend foundation for the DeTLeng Platform. Use the existing frontend without modification. Configure PostgreSQL as the primary database. Prepare the backend structure for Apache Airflow and dbt integration. Do not implement business pipelines yet. Focus only on project structure, configuration, database connectivity, and reusable foundations.
Iske baad hum Airflow integration ka alag task denge.
Meri ek aur recommendation
PostgreSQL ko local machine par install karein, Docker mein nahi (kam az kam Phase 1 ke liye).
Reason:
•	pgAdmin use karna aasaan hoga.
•	Debugging simple hogi.
•	Airflow se connection test karna straightforward hoga.
•	dbt configuration bhi seedhi rahegi.
Jab platform stable ho jaye, tab poore stack (Airflow + PostgreSQL + dbt) ko Docker Compose mein containerize kar denge. Is tarah pehle development simple rahegi aur deployment baad mein standardize ho jayegi.
