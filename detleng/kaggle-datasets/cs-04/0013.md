Phase 2 — DeTLeng Platform Integration
Iske baad hum Codex ko ye task denge:
Integrate the installed local services into the DeTLeng Platform.

Requirements:
- Connect Airflow to the platform.
- Connect PostgreSQL to the platform.
- Connect dbt to the platform.
- Use reverse proxy routing.
- Keep the frontend unchanged.
- Backend should expose:

/airflow
/postgresql
/dbt

All services must work from platform.detleng.com.
Uske baad dashboard ke buttons sirf UI nahi rahenge:
•	Open Airflow → https://platform.detleng.com/airflow
•	Open PostgreSQL → https://platform.detleng.com/postgresql
•	Open dbt → https://platform.detleng.com/dbt
