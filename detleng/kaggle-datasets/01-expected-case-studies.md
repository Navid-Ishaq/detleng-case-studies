# DeTLeng E-Commerce Analytics Case Study Program

## Dataset Source

The DeTLeng E-Commerce Analytics Program is built using the publicly available **Brazilian E-Commerce Public Dataset by Olist**, obtained from Kaggle:

**Dataset URL**

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce?resource=download

The dataset contains real-world e-commerce transactions and business records covering customers, orders, products, sellers, payments, reviews, and geographic information. It provides a comprehensive environment for practicing and demonstrating modern Data Engineering, ETL Development, Analytics Engineering, Data Warehousing, and Business Intelligence methodologies.

---

## Project Objective

The objective of this initiative is to transform a collection of raw operational datasets into a series of structured, analytics-ready business assets using:

* Google BigQuery
* SQL Development
* ETL & ELT Processing
* Data Quality Validation
* Analytics Engineering
* KPI Engineering
* Power BI Reporting
* Executive Business Intelligence

All datasets have been successfully acquired and loaded into the DeTLeng BigQuery environment, creating a complete foundation for a comprehensive E-Commerce Analytics Case Study Library.

---

## DeTLeng Implementation Approach

Each case study will follow the DeTLeng implementation methodology:

1. Business Context
2. Raw Data Assessment
3. Data Quality Analysis
4. SQL-Based Data Transformation
5. ETL / ELT Development
6. Analytics Dataset Construction
7. KPI Engineering
8. Dashboard Development
9. Business Insights & Recommendations
10. Technical Documentation

This approach ensures that every case study demonstrates both technical implementation and measurable business value.
