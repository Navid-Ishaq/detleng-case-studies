# CS-003 — Building an Analytics-Ready E-Commerce Dataset with Google BigQuery

## Case Study Objective

The purpose of this case study is to transform raw operational e-commerce datasets into a structured, analytics-ready data model suitable for reporting, dashboarding, KPI development, and advanced analytics.

This implementation serves as the foundation for all future DeTLeng E-Commerce Analytics case studies.

---

# Business Problem

Raw e-commerce data is distributed across multiple operational tables containing customers, orders, products, sellers, payments, reviews, and geographic information.

Business users cannot efficiently answer questions such as:

* What is total revenue?
* Which products perform best?
* Which sellers generate the highest sales?
* Which regions contribute most revenue?
* How satisfied are customers?
* What are the delivery performance trends?

The objective is to build a centralized analytics-ready dataset inside Google BigQuery.

# Data Quality Checks

## Customers

Duplicate Check

```sql
SELECT
customer_id,
COUNT(*)
FROM customers
GROUP BY customer_id
HAVING COUNT(*) > 1;
```

---

## Orders

Null Check

```sql
SELECT
COUNT(*)
FROM orders
WHERE order_id IS NULL;
```

---

## Products

Missing Categories

```sql
SELECT
COUNT(*)
FROM products
WHERE product_category_name IS NULL;
```

---

## Payments

Negative Values

```sql
SELECT *
FROM payments
WHERE payment_value < 0;
```
